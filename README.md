# Personal Portfolio

My personal developer portfolio — a site showcasing my projects, skills, and resume.

Built with plain HTML, CSS, and JavaScript.

## Live Site

https://akanksharawat22.github.io/personal-portfolio/

## Featured Projects

- **ResumeLens** — A resume analysis tool built with Python, Flask, and the Google Gemini API on the backend, and React + Vite on the frontend. Features ATS match scoring, skill gap analysis, resume rewriting suggestions, and PDF export.
- **Trenova** — An e-commerce website.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repo and open `index.html` in your browser — no build step required:

```bash
git clone https://github.com/akanksharawat22/personal-portfolio.git
cd personal-portfolio
open index.html
```
